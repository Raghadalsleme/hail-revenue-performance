# الشعار

- `hail_logo.png`: الشعار المستخدم في الترويسة وتقارير PDF — الملف الذي زوّدنا به صاحب المشروع بعد قص الهوامش الفارغة فقط (دون تغيير الشكل أو الألوان أو النسب).
- `hail_logo_as_provided.png`: الملف كما وصل.

لم يُرسم أي شعار أو يُعاد إنشاؤه. يُنصح بمطابقته مع النسخة المعتمدة لدى أمانة منطقة حائل، علمًا بأن الموقع الرسمي يعرض شعاره على: `https://amanathail.gov.sa/Portal/img/logo/logo.png`.
لاستبداله: ضع ملفًا جديدًا بالاسم نفسه (PNG/SVG/JPG/WebP). استخدام الشعار في نسخة عامة يحتاج موافقة الجهة المالكة له.

# منصة تنمية الإيرادات البلدية ومتابعة أداء الإدارات — نموذج أولي v2.0.0

> نموذج أولي للعرض، غير معتمد رسميًا من أمانة منطقة حائل. جميع البيانات تجريبية ولا تمثل أرقام الأمانة.

## الصفحات

| الصفحة | المحتوى |
|---|---|
| الإيرادات | المستهدف، المحقق، الفجوة، وكيف تُسد، والمصادر |
| الفرص | فرص مستخرجة من البيانات (تأجير، تجديد عقود، تحصيل)، اختيارها، والسيناريو، والفجوة المتبقية |
| أداء الأقسام | بطاقات الأقسام بالألوان، والاتجاه الشهري، وجدول المقارنة |
| إدخال البيانات | إدخال نتائج شهر، تعديل الأقسام، رفع وتنزيل الملفات |
| التقارير | PDF وExcel للإيرادات والأداء |

## الأرقام التجريبية

- المستهدف 100 مليون، المحقق 80 مليون، الفجوة 20 مليون.
- المتوقع أصلًا لبقية السنة 11.5 مليون، فتبقى فجوة متوقعة 8.5 مليون.
- 10 فرص؛ المختارة تلقائيًا (9) تضيف 2.0 مليون هذه السنة، فتبقى **6.5 مليون**. لا تكفي الفرص في أي سيناريو، والمنصة تعرض ذلك.

## التشغيل

- **الرابط المنشور:** على Streamlit Community Cloud من المستودع على GitHub.
- **على Mac:** انقر مرتين على `run_mac.command`، أو:

```bash
pip install -r requirements.txt
streamlit run app.py
```

## التحديث بعد أي تعديل

1. انسخ الملفات الجديدة إلى مجلد المستودع على جهازك.
2. في GitHub Desktop: **Commit to main** ثم **Push origin**.
3. يتحدث الرابط تلقائيًا خلال دقيقة أو اثنتين.
